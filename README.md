Teste de FastAPI com Docker

Este projeto foi desenvolvido com o objetivo de testar conhecimentos e habilidades na configuração, build e modificação em ambientes de container.

Usei o framework FastAPI rodando no servidor Uvicorn e expondo a porta 8000 para comunicação no navegador

Objetivos e aprendizados:

Conteinerização: Criação e otimização do ambiente isolado utilizando Docker.
Exposição de portas: Mapeamento das portas ("8000:8000") para acesso API do ambiente host.
Gerenciamento de logs: Catalogação, extração e análise de registros de eventos para manutenção de boas práticas e monitoramento.
Persistência de histórico: Versionamento do ecossistema de infraestrutura via Git e GitHub.


Muitas falhas de sintaxe e comandos tortos, o objetivo aqui é aprender na prática e não ser perfeito :)
